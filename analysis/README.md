# 분석 스크립트 (analysis)

참가자 원본 로그(JSONL)에서 지표를 다시 계산하고 2×2 피험자 내 분석을 한다. 결과 파일에는 참가자 데이터가 들어가므로 `analysis_out/`에 저장하고, 이 폴더는 git에서 제외한다.

## 실행

```bash
node analysis/extract.mjs "실험 결과 데이터"   # → analysis_out/per_condition.csv, per_trial.csv, extract_warnings.txt
python3 -I analysis/stats.py                    # → analysis_out/report.md
```

필요한 것: Node 18 이상, Python 3 + numpy + scipy + matplotlib (노트북은 pandas도 필요).

**주피터:** `analysis/analysis.ipynb`를 열고 위에서부터 실행하면 위 두 단계가 실행되고 표와 그래프가 노트북 안에 표시된다. 출력에는 참가자 데이터가 들어가므로 커밋 전에 *Edit → Clear Outputs of All Cells*를 한다.

## 규칙 (앱과 같음)

- **참가자 단위:** 로그 파일 하나가 참가자 한 명이다. 참가자 번호는 그룹마다 겹치므로(P01이 3명 등) 파일 시각으로 구분한다. 폴더 이름은 출력에 쓰지 않는다.
- **분석 범위:** 파일 안에서 마지막 `participant_start` 이후 이벤트만 쓴다. 재시작이 있으면 그 조건은 마지막 시도만 쓴다(`typing_start` 기준).
- **의도 키:** 목표 문장과 입력을 정렬해서 정한다(`alignTrial`). 앱의 `js/metrics.js`를 그대로 불러와 쓰기 때문에 지표 정의가 앱과 어긋나지 않는다.
- **확인 방법:** 추출한 값을 앱이 내보낸 요약 CSV와 비교해서 일치하는지 확인했다(TLX 소수 반올림 차이만 있음).

## 통계 (`stats.py`)

**사전 계획(11/3, 데이터 수집 전에 정함):**
- 2×2 반복측정 분산분석
- 사전 지정 비교 H1(B vs D)·H4(A vs C) + Holm 보정
- 비모수 방법 병행

**사후 추가(확인용, 결론을 바꾸지 않음):**
- ART 분산분석
- arcsine 변환
- 95% 신뢰구간
- 섀도 판정
- 순서 확인
- 그래프

| 방법 | 무엇을 하나 | 이 실험에 맞는 이유 |
|---|---|---|
| 분석 단위 = 참가자 × 조건 평균 | 한 사람의 키 입력 수백 개를 조건별 평균 하나로 줄인다 | 같은 사람의 키 입력은 서로 독립이 아니므로, 하나하나를 표본으로 세면 p값이 부풀려진다 |
| 2×2 반복측정 분산분석 | 키보드 효과, 손 상태 효과, 둘의 상호작용을 한 번에 검정한다 | 같은 사람이 4조건을 모두 하는 설계다. H2(장갑에서 이득이 더 큼)는 상호작용 검정으로만 직접 확인할 수 있다. 수준이 2개라 구형성 가정이 자동으로 충족된다 |
| ART 분산분석 | 값을 순위로 바꾼 뒤 같은 분산분석을 한다 (Wobbrock et al., CHI 2011) | 오류율은 치우친 분포이고 불편도는 서열 척도다. 정규성 가정 없이 상호작용까지 검정할 수 있는 HCI 표준 비모수 방법이다 |
| 사전 지정 비교 + Holm | B vs D, A vs C 두 비교만 하고, 검정 횟수만큼 기준을 엄격하게 조정한다 | 가설(H1·H4)을 직접 검정한다. 모든 쌍을 비교하지 않고 미리 정한 두 개만 본다 |
| 대응 t검정 + Wilcoxon | 사람별 차이의 평균(t)과 순위(Wilcoxon)로 각각 검정한다 | 두 방법의 결론이 같으면 분포 가정에 흔들리지 않는 결과다 |
| 95% 신뢰구간, dz, 상대 변화 | 차이가 얼마나 큰지를 보여 준다 | p값은 차이가 있는지만 알려 준다. 크기는 따로 보여야 한다 |
| Shapiro-Wilk | 사람별 차이가 정규분포인지 확인한다 | t검정의 가정을 점검한다 |
| arcsine-sqrt 변환 | 비율 데이터를 변환한 뒤 다시 분석한다 | 0% 근처에서 퍼짐이 작아지는 비율 데이터의 특성을 보정한다 |
| 섀도 판정 | 같은 터치를 두 판정으로 다시 계산한다 | 사람의 적응을 빼고 판정 방식만의 효과를 본다(참고용) |
| 순서 확인 | 보정을 먼저 한 사람과 나중에 한 사람을 비교한다 | 라틴 방격이 순서 효과를 상쇄했는지 확인한다 |

**지표의 역할:**
- **주 지표(이웃 키 오류율):** 이것만 확증 결론에 쓴다.
- **보조·주관 지표:** 뒷받침 근거로만 보고한다.
- **불편도:** 서열 척도라 Wilcoxon·ART 결과를 주 결과로 본다.

**구현 확인:**
- 분산분석은 고전적인 제곱합 계산과 일치했다.
- ART는 효과가 없는 모의 데이터로 돌렸을 때 오탐률이 약 5%였다.
