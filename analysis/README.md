# 분석 (analysis)

익명화 원자료(참가자 로그)에서 출발해 지표 계산, 통계 검정, 그래프까지 모두 **파이썬 코드로 직접** 실행한다. 중심은 노트북 `analysis.ipynb`다. 위에서부터 셀을 실행하면 각 단계의 중간 표와 결과가 차례로 나온다.

## 실행

1. 익명화 원자료를 저장소의 `data/raw/`에 둔다(`S01.jsonl … S12.jsonl`). 공개 저장소에는 없으며, e-class 제출용 압축 파일에 들어 있다.
2. 필요한 라이브러리를 설치한다.
   ```bash
   pip install -r analysis/requirements.txt
   ```
3. 주피터에서 `analysis/analysis.ipynb`를 열고 위에서부터 실행한다(Shift + Enter).
   ```bash
   jupyter notebook
   ```
   표와 그래프는 `analysis_out/`에도 저장된다.

> 실행 결과에는 참가자 데이터가 들어간다. 노트북을 다시 커밋하기 전에 *Edit → Clear All Outputs* 로 출력을 지운다. `data/raw/`와 `analysis_out/`은 git에서 제외돼 있다.

## 분석 규칙

- **참가자 구분:** 파일 하나가 참가자 한 명이다. 앱의 참가자 번호는 순서 그룹 번호라 겹치므로 쓰지 않는다.
- **분석 범위:** 마지막 `participant_start` 이후 이벤트만 쓴다. 재시작이 있으면 그 조건은 마지막 시도만 쓴다(이번 12명은 재시작 0).
- **의도 키:** 목표 문장과 최종 입력을 최소 편집 거리로 정렬해서 정한다. 이웃 키는 키 사각형 사이 거리가 0.5 키 폭 이하인 키다.
- **분석 단위:** 참가자 × 조건 평균이다(키 입력을 독립 표본으로 세지 않음). 단, GLMM은 키 입력 단위로 분석한다.
- **검증:** 파이썬 지표 계산은 앱이 내보낸 요약 CSV와 912개 값이 모두 일치했다. 이웃 키 표도 앱과 같다.

## 통계 방법과 이유

**사전 계획(실험계획서 A8, 2026-11-03, 데이터 수집 전):**
- 주 분석: 2×2 반복측정 분산분석. 사전 지정 비교 B vs D(H1), A vs C(H4)에 Holm 보정을 적용한다.
- 정규성이 의심되면 arcsine 변환이나 비모수 방법(Wilcoxon, ART)을 쓴다.
- 민감도 분석(선택): 키 입력 단위 로지스틱 혼합모형(GLMM).
- 부 지표는 탐색적으로 보고한다.
- 보조 분석: 오프라인 재생.
- 효과 크기(dz, 95% 신뢰구간)를 함께 보고한다.

| 방법 | 무엇을 하나 | 이 실험에 맞는 이유 |
|---|---|---|
| 2×2 반복측정 분산분석 | 키보드 효과, 손 상태 효과, 상호작용을 한 번에 검정 | 같은 사람이 4조건을 모두 하는 설계다. H2(장갑에서 이득이 더 큼)는 상호작용으로만 직접 검정할 수 있다. 수준이 2개라 구형성 가정이 자동 충족된다 |
| ART 분산분석 | 순위로 바꾼 뒤 같은 분산분석 (Wobbrock et al., CHI 2011) | 오류율은 치우친 분포이고 불편도는 서열 척도다. 정규성 가정 없이 상호작용까지 검정하는 HCI 표준 비모수 방법이다 |
| 사전 지정 비교 + Holm | B vs D, A vs C만 비교하고 검정 횟수만큼 기준을 엄격하게 | 가설을 직접 검정하고, 여러 번 검정해서 생기는 우연한 유의를 막는다 |
| 대응 t검정 + Wilcoxon | 사람별 차이를 평균과 순위로 각각 검정 | 두 결론이 같으면 분포 가정에 흔들리지 않는다 |
| 95% 신뢰구간, dz, 장갑 손해 감소율 | 차이의 크기 | p값은 차이가 있는지만 알려 준다 |
| Shapiro-Wilk | 차이의 정규성 확인 | t검정의 가정을 점검한다 |
| arcsine-sqrt 변환 | 비율을 변환해 다시 분석 | 0% 근처 비율 데이터의 분산 특성을 보정한다 |
| GLMM (베이즈 혼합모형 + GEE) | 키 입력 하나하나의 이웃 키 오류(0/1)를 로지스틱 모형으로 분석. 참가자·문장 차이를 무작위 효과로 분리 | 평균 비율 분석의 한계(사람마다 키 입력 수가 다름, 0 근처 분포)를 보완하는 민감도 분석이다 |
| 오프라인 재생 (섀도 판정) | 같은 터치를 기본·보정·M0·M1 판정으로 다시 계산 | 사람의 적응을 빼고 판정 방식만의 효과를 본다(보조 증거) |
| 순서 효과 확인 | 진행 위치별 평균, 보정을 먼저 한 사람 vs 나중에 한 사람 | 라틴 방격이 순서 효과를 상쇄했는지 확인한다 |

**구현 확인:**
- 분산분석은 고전적인 제곱합 계산과 일치했다.
- ART는 효과가 없는 모의 데이터에서 오탐률이 약 5%였다.

**GLMM 한계:**
- statsmodels에는 빈도주의 이항 GLMM이 없다.
- 그래서 참가자·문장 무작위 효과를 모두 넣는 베이즈 모형(변분 추정)과, 참가자 군집 강건 표준오차를 쓰는 GEE를 함께 보고한다.
